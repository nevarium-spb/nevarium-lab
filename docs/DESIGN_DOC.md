# Невариум ЛАБ ИИ — Design Doc (Think → Plan)

## 1. Office Hours — шесть вопросов

**Кто клиент?** Малый и средний бизнес в РФ/СНГ (e-commerce, услуги, онлайн-школы, B2B-продажи), у которого нет своей команды по ИИ, но есть рутина: контент, ответы клиентам, отчёты, лидогенерация.

**Какую боль решаем?** «Слышал про нейросети, но не понимаю, с чего начать и что это даст в деньгах». Продаём не технологии, а результат: часы, снятые с сотрудников, и рост конверсии.

**Почему мы?** Лаборатория одного эксперта-практика: системный подход, каскадные промпты, готовые GPT-ассистенты и шаблоны для 15+ ниш (HR, e-commerce, маркетплейсы, лидогенерация, копирайтинг, SMM). Личная работа без конвейера агентства.

**Что 10-звёздочный продукт?** Сайт, который сам демонстрирует продукт: посетитель общается с ИИ-ассистентом «Нева» прямо на сайте и видит, как это работало бы у него.

**Минимальный сильный скоуп?** 6 страниц + чат-бот. Никакого блога и личных кабинетов на старте.

**Метрика успеха?** Заявка (лид) через чат-бот или форму контакта.

## 2. Позиционирование

- Название: **Невариум ЛАБ ИИ** (Nevarium LAB AI)
- Слоган: «Внедряем ИИ в бизнес. Измеримо.»
- Тон: уверенный, конкретный, без хайпа. Цифры вместо прилагательных.

## 3. Услуги (из реальных компетенций владельца)

1. **GPT-ассистенты под ключ** — системные инструкции, tone of voice, ролевые и каскадные промпты.
2. **Чат-боты для продаж и поддержки** — сценарии, квалификация лидов, автоматизация (SendPulse).
3. **ИИ-контент и маркетинг** — копирайтинг, SMM, сценарии Reels, УТП, воронки.
4. **ИИ-таблицы (GPT Sheets)** — каскады из 10–100 промптов: анализ ЦА, HR, e-commerce, лидогенерация.
5. **Генерация визуала и видео** — Midjourney, Flux, Kandinsky, Kling; дизайн, логотипы, ролики.
6. **Обучение команды** — промпт-инжиниринг: 16 техник, библиотека ассистентов.

> **Разделы 4–7 актуализированы в августе 2026 года** — исходная версия описывала
> стек и дизайн-систему на момент первого планирования, до редизайна «Индиго
> Лайв» и до миграции на Astro. Разделы 1–3 (позиционирование, услуги) не
> менялись — они не зависят от технической реализации. Живой источник истины

## 5. Архитектура

- **Стек:** Astro 7 + TypeScript. React используется точечно — только там, где
  нужна интерактивность (формы, чат-бот, шапка, фон, FAQ-аккордеон), через
  `@astrojs/react`. Статичные страницы React вообще не грузят в браузер.
  `react-router-dom` не используется — переходы между страницами обычные,
  каждая страница отдаётся готовым HTML-файлом.
- **Стили:** чистый CSS, дизайн-токены в `:root`, глассморфизм-утилиты. Один
  файл `src/styles/global.css` на весь сайт — не тронут миграцией намеренно.
- **Анимации:** CSS keyframes (aurora-фон, свечение); общий
  `IntersectionObserver` в `src/layouts/Base.astro` для scroll-reveal
  (`class="reveal"`) и разгона счётчиков цифр (`[data-stat]`) — один
  наблюдатель на весь сайт, не React-хук.
- **Изображения:** инлайн-SVG (иконки, панель внедрения) + self-hosted шрифты
  (Poppins/Open Sans, без Google Fonts) — быстро, без утечки IP пользователей
  третьей стороне.
- **Чат-бот «Нева»:** клиентский сценарный ассистент (React-остров,
  `client:idle`): быстрые ответы, ветки (услуги/цены/как начать), сбор лида
  (имя + телефон) через `sendLead()` в CRM, typing-индикатор, хранение
  диалога в sessionStorage.
- **SEO:** свой `title`/canonical/Open Graph/Twitter Card на каждой странице
  (не через JS — прямо в HTML), JSON-LD `ProfessionalService` + `Service`,
  `sitemap.xml` и `robots.txt` генерируются автоматически.
- **A11y:** контраст ≥ 4.5:1 для текста, focus-visible, aria-метки,
  prefers-reduced-motion.

## 6. Дизайн-система «Индиго Лайв»

- **Настроение:** глубокий индиго тёмной темы по умолчанию + переключаемая
  светлая, живой canvas-фон с созвездием (реагирует на курсор).
- **Фон:** тёмная тема — `#0d1030`; переключение через `data-theme` на `<html>`,
  сохраняется в `localStorage`.
- **Глассморфизм:** `backdrop-filter: blur(18px)`, фон `rgba(255,255,255,0.05)`,
  бордер `rgba(255,255,255,0.1)`.
- **Акценты:** скай `#38bdf8`, индиго `#6366f1`, кобальт `#4f46e5`, изумруд `#10b981`.
- **Типографика:** Poppins (заголовки) + Open Sans (текст), self-hosted.
  У Poppins нет кириллического набора символов — заголовки на кириллице
  рисуются шрифтом-заменой из списка `font-family`, это факт про сам шрифт,
  а не баг.
- **Скругления:** 28px (lg), 20px (md), 14px (sm).
- **Мобильная версия:** burger → стеклянная шторка, стек-раскладка, чат-бот на весь экран.

## 7. Тест-план

1. Все 8 маршрутов открываются напрямую (не только по ссылке с другой
   страницы) и переживают обновление страницы (F5) — у каждого свой HTML,
   SPA-fallback не нужен.
2. Навигация: desktop-меню и мобильный burger.
3. Чат-бот: открытие, быстрые ответы, ветка лида, отправка в CRM, честная
   ошибка при недоступной CRM (не ложный успех).
4. Формы («Контакты», запрос по ПДн): валидация, honeypot, честная ошибка
   при недоступной CRM, защита от повторной отправки.
5. Тёмная и светлая тема — без мигания белым при перезагрузке.
6. Консоль без ошибок; отзывчивость на 375px и 1280px.
7. `npm run build` (`astro check && astro build`) проходит без ошибок,
   предупреждений и подсказок.
