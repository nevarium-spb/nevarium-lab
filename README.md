# Невариум ЛАБ ИИ

Сайт-визитка лаборатории внедрения ИИ в малый и средний бизнес. Astro 7 + TypeScript,
дизайн-система «Индиго Лайв» (глассморфизм, тёмная тема по умолчанию + переключаемая
светлая), встроенный чат-бот «Нева».

React используется точечно — только там, где нужна интерактивность (формы, чат-бот,
шапка, живой фон, FAQ-аккордеон). Статичные страницы отдаются готовым HTML без единого
килобайта JS.

## Запуск

```bash
npm install
npm run dev        # дев-сервер на http://localhost:5173
npm run build      # astro check && astro build — production-сборка в dist/
npm run preview    # предпросмотр настоящей статичной сборки (порт 4321)
```

## Структура

| Путь | Что это |
|---|---|
| `src/pages/*.astro` | Страницы: Главная, Услуги, Кейсы, Тарифы, Лаборатория, Контакты, Политика ПДн, 404 |
| `src/layouts/Base.astro` | Общая оболочка: `<head>`, SEO-теги, шапка, подвал, живой фон, чат-бот, общие скрипты (scroll-reveal, счётчики) |
| `src/components/*.tsx` | React-острова: `Header`, `ThemeToggle`, `LiveBackground`, `Chatbot`, `ContactForm`, `PdRequestForm`, `FaqAccordion`, `Logo` |
| `src/components/*.astro` | Статичные компоненты: `Footer`, `SectionHead`, `Stat`, `HeroPanel` |
| `src/data/content.tsx` | Весь контент сайта: услуги, кейсы, тарифы, FAQ, шаги процесса — правится в одном месте |
| `src/data/bot.ts` | Сценарий чат-бота: дерево узлов + маршрутизация свободного ввода |
| `src/lib/leads.ts` | Отправка заявок и запросов по ПДн в Невариум CRM |
| `src/styles/global.css` | Дизайн-система: токены, глассморфизм, анимации, адаптив (не тронут миграцией на Astro) |
| `public/fonts/` | Self-hosted шрифты (Poppins, Open Sans) — не Google Fonts |
| `docs/DESIGN_DOC.md` | Проектный документ: позиционирование, архитектура, тест-план |
| `docs/MIGRATION_PLAN.md` | План перехода с React SPA на Astro (историческая справка) |

## Чат-бот «Нева»

Сценарный ассистент: ветки «услуги / цены / как начать», сбор лида (имя + контакт),
понимание свободного текста по ключевым словам, история диалога в `sessionStorage`.
Собранные лиды отправляются в CRM через `src/lib/leads.ts` — это уже не демо-режим.

## CRM

Форма на «Контактах», чат-бот и форма запроса по персональным данным на «Политике»
отправляют заявки в Невариум CRM через `src/lib/leads.ts` (`${VITE_CRM_API}/api/leads`
и `/api/pd-requests`). Если CRM недоступна — пользователю показывается честная ошибка
с запасным каналом связи (почта, MAX), а не фальшивый экран успеха.

## Деплой

`git push origin main` → Vercel автоматически собирает и выкатывает прод. Ручной
`vercel deploy --prod` не нужен, разве что для отладки. SPA-fallback в `vercel.json`
не нужен — каждая страница отдаётся собственным HTML-файлом.
